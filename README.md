# Unistream Info API: автотесты

Автотесты на Java для Info API Юнистрим (тестовый стенд `https://slt-test.info.api.unistream.com`).

## Стек
- Java 17
- JUnit 5
- RestAssured
- Maven (или Gradle)

## Содержание
1. Задание 1. Комиссия за безадресный перевод
2. Задание 2. Адрес ближайшего отделения
3. Задание 3. Тест-кейсы регистрации клиента
 
## Запуск
```
mvn test
```
(для Gradle: `gradle test`)

Тесты обращаются к тестовому стенду, поэтому нужен доступ в интернет.

## Что реализовано

### Задание 1. Комиссия за безадресный перевод
Запрос `POST /api/v2/transfer/calculate`: отправитель банк `10400`, страна получателя Армения (`ARM`), сумма 1000 RUB, получатель не указан (безадресный перевод).

**Результат: комиссия = 100.0 RUB** (поле `fees[0].acceptedTotalFee`).

Проверки: статус 200, комиссия присутствует в ответе, комиссия не отрицательная.

### Задание 2. Адрес ближайшего отделения
Запрос `GET /api/v1/poses?filter.term=Балашиха&rows=1`, адрес берётся из ключа `address` первого элемента списка.

**Результат: «Московская область, Балашиха, Советская, 13»**

Проверка: `assertEquals` фактического адреса с ожидаемым.

## Задание 3
Тест-кейсы для регистрации клиента по схеме `person.full`: [test-cases-registration.xlsx](test-cases-registration.xlsx)

- 101 кейс: 26 позитивных и 75 негативных.
- Техники: граничные значения, классы эквивалентности, проверка обязательности, формата и типов данных.
- На листе «Вопросы к аналитику» собраны неоднозначности схемы (формат телефона, справочник стран, ограничения на дату рождения и др.).
